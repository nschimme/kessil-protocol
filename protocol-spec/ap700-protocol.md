# AP700 legacy reference

This repository does not include the AP700 Home Assistant script or reproduce its implementation. The original discussion and source are available in the [Reef2Reef AP700 reverse-engineering thread](https://www.reef2reef.com/threads/kessil-ap700-reverse-engineered.1154371/).

The AP700 uses product-specific legacy control and update interfaces. Do not assume they are compatible with K-Link fixture control, the legacy WiFi Dongle API, or Controller X. This project has not validated AP700 behavior against hardware.
