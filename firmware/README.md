# Firmware analysis boundary

This repository documents protocol behavior inferred from publicly available product materials and locally analyzed software. It does not distribute firmware, applications, updater executables, extracted binaries, or extraction utilities.

Some analysis inputs were vendor updater packages and an Android application package obtained from a third-party distributor. Their contents remain subject to their owners' rights and any applicable terms. This repository does not endorse or link to unofficial software distribution sources. No firmware image in this project is offered for download, and these notes do not establish that any image is current, authentic, or safe to install.

Firmware-update behavior is described only at a high level in the protocol references. No update was attempted on a device. Do not use these notes as an update procedure. See [the protocol index](../protocol-spec/README.md) and [evidence limits](../protocol-spec/protocol-evidence.md) for the scope of the findings.
